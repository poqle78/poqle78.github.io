### 10. Трансформация данных

### 11. Созданные признаки
- **Age_group** — возрастные группы: Child (0-12), Teen (13-18), Young Adult (19-35), Adult (36-60), Senior (60+)

### 13. Обработка выбросов
**Для признака Fare:**
- Построен boxplot для визуализации распределения
- Применен IQR-метод для выявления выбросов
- Q1 (25-й перцентиль): 7.91
- Q3 (75-й перцентиль): 31.00
- IQR = Q3 - Q1 = 23.09
- Нижняя граница: Q1 - 1.5×IQR = -26.73
- Верхняя граница: Q3 + 1.5×IQR = 65.64
- Применена winsorization (5% с каждой стороны)

**Для признака Age:**
- Визуализировано распределение (гистограмма с KDE)
- Заменены экстремальные значения на 95-й перцентиль (~65 лет)

### 14. Выявленные выбросы
**Fare:**

- После winsorization: значения ограничены 5-м и 95-м перцентилями

**Age:**
- Выбросы не обнаружены (распределение близкое к нормальному)
- Применено ограничение сверху на уровне 95-го перцентиля

### 15. Методы обработки
- **IQR-метод (Interquartile Range):** Основан на межквартильном размахе. Выбросы определяются как значения за пределами [Q1 - 1.5×IQR; Q3 + 1.5×IQR]. Преимущества: устойчив к выбросам, не требует предположений о распределении.
- **Winsorization:** Замена экстремальных значений на перцентили. Применено 5% winsorization для Fare. Сохраняет размер выборки, в отличие от удаления выбросов.
- **Ограничение перцентилем:** Для Age значения выше 95-го перцентиля заменены на сам перцентиль. Сохраняет распределение основной массы данных.
