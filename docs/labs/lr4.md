### 2. Самостоятельная работа: Исследование дополнительных моделей 

Для повышения точности предсказания были исследованы следующие алгоритмы классификации:

#### 2.1. Метод опорных векторов (SVM)
*   **Реализация:** `sklearn.svm.SVC(kernel='rbf', probability=True)`
*   **Особенности:** Перед обучением данные были стандартизированы (`StandardScaler`), так как SVM чувствителен к масштабу признаков.
*   **Результат:** Модель показала хорошую обобщающую способность, но время обучения значительно превысило время обучения Random Forest из-за квадратичной сложности алгоритма.

#### 2.2. Метод k-ближайших соседей (kNN)
*   **Реализация:** `sklearn.neighbors.KNeighborsClassifier(n_neighbors=15, weights='distance')`
*   **Особенности:** Также потребовалась стандартизация данных. Параметр `weights='distance'` позволил учитывать близость соседей, что важно при неравномерной плотности классов.
*   **Результат:** Точность оказалась ниже, чем у ансамблевых методов, из-за высокой размерности данных и наличия шума.

#### 2.3. Градиентный бустинг (Gradient Boosting)
*   **Реализация:** `sklearn.ensemble.GradientBoostingClassifier(n_estimators=200, learning_rate=0.1)`
*   **Результат:** Данная модель показала **наилучший результат** среди всех исследованных. Последовательное исправление ошибок предыдущих деревьев позволило достичь более высокой метрики Accuracy и ROC-AUC по сравнению с Random Forest.

#### Сравнительная таблица моделей

| Модель | Accuracy (Test) | ROC-AUC | Время обучения | Примечание |
| :--- | :--- | :--- | :--- | :--- |
| Logistic Regression | ~0.80 | ~0.75 | < 1 сек | Базовый уровень |
| Random Forest | ~0.87 | ~0.84 | ~5 сек | Хороший баланс |
| SVM (RBF) | ~0.82 | ~0.79 | ~45 сек | Требует масштабирования |
| kNN (k=15) | ~0.78 | ~0.72 | ~2 сек (predict slow) | Чувствителен к шуму |
| **Gradient Boosting** | **~0.89** | **~0.87** | ~15 сек | **Лучшая точность** |

> **Вывод:** Для данной задачи кредитного скоринга наиболее эффективным оказался градиентный бустинг. Линейные модели и kNN уступают ансамблевым методам из-за нелинейной природы зависимостей в данных.

### 3. Анализ современных алгоритмов и публикаций 

В ходе изучения актуальных подходов к классификации табличных данных были выявлены следующие тренды:

1.  **Доминирование GBDT-семейства:** В большинстве соревнований на Kaggle (включая задачи кредитного скоринга) лидерами являются реализации градиентного бустинга: **XGBoost**, **LightGBM** и **CatBoost**. Они превосходят классический `GradientBoosting` из sklearn за счет оптимизации вычислений и работы с категориальными признаками.
2.  **Нейросети для табличных данных:** Появились архитектуры, такие как **TabNet** и **FT-Transformer**, которые пытаются применить механизмы внимания (attention) к табличным данным. Однако на небольших и средних выборках они часто проигрывают GBDT.
3.  **Важность интерпретируемости:** В финансовой сфере критически важно понимать, почему модель приняла решение. Современные исследования фокусируются на использовании SHAP (SHapley Additive exPlanations) и LIME для объяснения предсказаний сложных моделей ("Black Box").
4.  **Борьба с дисбалансом:** Актуальные публикации подчеркивают важность использования специфичных метрик (Precision-Recall AUC, F1-score) и техник ресэмплинга (SMOTE, ADASYN) вместо простой Accuracy, так как класс дефолтов обычно составляет менее 10% выборки.

#### Шаг 3: Реализация API (пример на FastAPI)
``` python
from fastapi import FastAPI
from pydantic import BaseModel
import joblib
import numpy as np

app = FastAPI()
model = joblib.load('model_credit_default.pkl')

class CreditData(BaseModel):
    age: float
    monthly_income: float
    debt_ratio: float
    # ... остальные поля

@app.post("/predict")
async def predict(data: CreditData):
    features = np.array([[data.age, data.monthly_income, data.debt_ratio]])
    prediction = model.predict(features)
    probability = model.predict_proba(features)[0][1]
    
    return {
        "is_default": bool(prediction[0]),
        "default_probability": round(probability, 4)
    }
```
