## 3. Ход выполнения

### 3.1. Подготовка окружения и настройка ноутбука

В первую ячейку ноутбука была добавлена информация об исполнителе. Импортированы необходимые библиотеки для работы с HTTP-запросами, парсинга HTML, работы с регулярными выражениями и обработки данных:

```python
import os
import re
import time
import random
import requests
import pandas as pd
from bs4 import BeautifulSoup
```

Создана директория для хранения детального контента:

```python
os.makedirs('news_content', exist_ok=True)
```

### 3.2. Сбор общих данных о новостях

Был реализован парсинг главной страницы сайта. С помощью библиотеки BeautifulSoup и CSS-селекторов были извлечены ссылки на новости. Для каждой ссылки с помощью регулярных выражений был получен целочисленный идентификатор:

```python
re.search(r'/(\d+)/?$', url)
```

Также были собраны заголовки, даты публикации и полные URL-адреса.

### 3.3. Детальный парсинг каждой новости

Для сбора детальной информации был написан цикл, который проходит по всем собранным URL. Чтобы избежать блокировки со стороны сервера, между запросами добавлена случайная задержка:

```python
time.sleep(random.uniform(0.5, 1.5))
```

Для извлечения данных были написаны отдельные функции:

- **get_news_id(url)** — достает числовой ID из URL
- **get_news_date(soup)** — находит дату в теге `<time>` внутри `<article>`
- **get_views(soup)** — извлекает количество просмотров из тега `<span class="icon eye">`
- **get_text(soup)** — извлекает основной текст из `div.content.js-mediator-article`
- **get_tags(soup)** — собирает теги из ссылок, содержащих `/ru/search/?tag=`

Для борьбы с **вариативностью верстки** и очистки от мусора используются методы decompose() для удаления тегов div.poster, script, style, а также фильтрация подписей к фото и источникам.

### 3.4. Сохранение результатов

Собранные данные были преобразованы в объекты pandas.DataFrame. Для исключения дубликатов применен метод drop_duplicates(). 

Данные сохранены в два файла с кодировкой utf-8-sig для корректного отображения кириллицы в Excel:

1. `general_news.csv` — общие данные
2. `news_content/news_content.csv` — детальные данные
