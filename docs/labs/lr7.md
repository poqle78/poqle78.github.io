## Анализ текста


### 1. Цель работы
Освоить методы векторизации текста, реализовать и сравнить алгоритмы классификации, исследовать влияние n-грамм на качество модели.

### 2. Задача
Бинарная классификация тональности текстов: определение, является ли сообщение положительным или отрицательным.

### 3. Методы
- **Векторизация**: TF-IDF с различными диапазонами n-грамм
- **Алгоритмы**: Logistic Regression, XGBoost, Random Forest
- **Оценка**: precision, recall, f1-score, accuracy

### 4. Ход работы
1. Загрузка и подготовка данных, разделение на обучающую и тестовую выборки
2. Векторизация текста с помощью TfidfVectorizer
3. Обучение трёх моделей классификации
4. Эксперимент с биграммами и триграммами
5. Сравнение результатов по метрикам качества

### 5. Результаты
- Наилучшее качество показал XGBoost, Logistic Regression продемонстрировал сопоставимые результаты при меньших вычислительных затратах
- Увеличение размера n-грамм привело к снижению точности из-за разреженности признакового пространства
- Униграммы оказались оптимальным выбором для классификации коротких текстов

### 6. Выводы
1. Для задач классификации коротких текстов эффективнее использовать униграммы с TF-IDF
2. Градиентный бустинг (XGBoost) и линейные модели показывают наилучшие результаты на разреженных текстовых данных
3. Длинные n-граммы не дают прироста качества, но увеличивают размерность и время обучения
4. Предобработка (удаление стоп-слов, пунктуации) может как улучшать, так и ухудшать результат в зависимости от задачи
